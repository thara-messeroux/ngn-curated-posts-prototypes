Why the live stories are affordable here

This nearly did not ship. The index endpoint returns configuration, not stories, and the codebase already notes that "behind one request per instance on the page, is seconds". That is a cost of the single-column layout, not of the data: in two panes only the selected shelf needs stories, so it is one request on selection rather than 47 on load. Measured at 1.5s for one instance against a cold cache, which is fine once and would not have been fine forty-seven times.

One new read-only endpoint carries it, wrapping a method the PHP suite already covers. The layout is what makes the feature possible, rather than the feature being blocked by the layout.
